# MIT 14.33: Research and Communication in Economics

Course materials for the Fall 2026 offering of MIT 14.33, *Research and Communication in Economics: Topics, Methods, and Implementation*.

## Course materials

- **[Syllabus](docs/syllabus/syllabus.pdf):** Course calendar, assignments, grading, and policies.
- **[Slides](docs/slides/):** Numbered folders contain lecture slides. `feedback_start` and `feedback_mid` contain responses to student feedback.
- **[Notes and exercises](docs/notes/):** Setup guides, practical reference notes, and pre-class exercises.

Open PDFs for reading or printing. For interactive slides, download the HTML file and open it in your browser.
